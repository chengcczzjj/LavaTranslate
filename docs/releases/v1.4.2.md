### Windows 1.4.2

- **Protect small text beside large headings.** Translations now check neighboring text across the full line height and avoid text that has already been laid out, including untranslated labels and pending blocks.
- **Keep wrapping inside available space.** Font reduction and wrapping respect neighboring columns, following paragraphs and the screenshot edges. Background patches also avoid nearby text and icons.
- **Handle text that still cannot fit.** The overlay shows an ellipsis instead of extending into other text. Hover over a shortened block to see its full translation; copying and side-by-side view retain the complete text.
- **Correct installer file selection.** Windows and Mac packaging rules exclude local development data, source files and old installers.

This release provides the Windows x64 installer and automatic-update files. Android remains at 1.4.1; its existing update manifest is retained. No macOS installer is included.

### Windows 1.4.2 更新

- **保护大标题旁边的小字**：按整条行高检查相邻文字，避让已经排好的译文、保留原文的标签和尚未翻译的文字。
- **限制换行范围**：缩小字号和换行时，避让旁边的栏、下方正文和截图边界；背景遮盖也不会涂掉邻近文字与图标。
- **空间不足时省略显示**：取消无限向下换行或横向展开的兜底。省略的块可以悬停查看完整译文，复制和并排对照仍保留全文。
- **修正安装包文件范围**：Windows 和 Mac 打包规则排除本地开发数据、源码及旧安装包。

本次发布 Windows 64 位安装包及自动更新文件。安卓仍为 1.4.1，保留原有更新索引；本次不提供 Mac 安装包。
