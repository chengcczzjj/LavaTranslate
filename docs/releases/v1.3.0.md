### New

- **Type to translate.** Press the hotkey twice (<kbd>Alt</kbd>+<kbd>Q</kbd> <kbd>Q</kbd>) to skip the screenshot and type a sentence. LavaTranslate waits until you pause (or press <kbd>Enter</kbd>) and translates into the language you used last. <kbd>Enter</kbd> copies and closes.
- **Sign in with ChatGPT.** Plus / Pro subscribers can translate with their plan's usage instead of an API key. This uses OpenAI's official sign-in for open-source apps.
- **One API key box for every provider.** Paste a key from any provider and LavaTranslate works out whose it is, either from its format or by trying it. If it can't tell, it asks you. Saved services appear as chips you can switch between, and each provider's key instructions sit at the bottom of the page.
- **Easier to find updates.** The tray menu now has **检查更新 (Check for updates)** and shows download progress. The Settings sidebar shows the version and update status, and the About page explains the update rules.

### Changed

- The reply assistant waits until you've finished typing (~1 s pause) before translating, instead of translating while you type.
- Claude is now called through Anthropic's OpenAI-compatible endpoint, so the separate Claude module is gone.
- When the model returns text that's identical to the original, LavaTranslate now leaves the original pixels on screen instead of redrawing them. With "thinking" turned off, models often forgot to mark such text.
- Product, app and project names are no longer translated.

- **输入文字翻译**：连按两次快捷键（Alt+Q Q）不截图，直接输入一句话；停下来（或按 Enter）才翻译，默认译成上次用的语言，Enter 复制并关闭；
- **用 ChatGPT 登录**：Plus / Pro 会员直接用会员额度翻译，不需要 API Key（OpenAI 为开源软件提供的官方方式）；
- **一个 API Key 输入框通吃各家**：粘贴任意一家的 Key，按格式或实际连接自动识别是哪家，识别不出来再让你选；填过的服务以小标签保存，点一下切换；各家获取 Key 的步骤放在页面底部；
- **更新更好找**：托盘菜单加了「检查更新」和下载进度；设置左下角显示版本和更新状态；「关于」页写明了更新规则；
- 回复助手改为等你写完（停顿约 1 秒）再翻译，不再边打边翻；
- Claude 改走 Anthropic 的 OpenAI 兼容接口，去掉了单独的 Claude 模块；
- 模型照抄原文时自动保留原图文字，不再重绘（关闭思考后模型常漏标）；产品、应用、项目名不再被翻译。
