### Windows 与 Mac 1.4.10

- **钉图可以收起。** 双击钉在桌面的图片，收起为桌面图标大小的小方块；再次双击恢复收起前的尺寸。小方块可以拖动，右键点击即可关闭。
- **钉住当前原图。** 按住 Alt 查看原图时点击钉图，会保留原图；Mac 使用 Option。
- **工具条更简洁。** 语言区域只展示目标语言，右侧新增自动翻译勾选项，悬停可查看说明。关闭自动翻译后，可点击翻译按钮手动翻译。
- **常用操作更集中。** 翻译、对话、对照按钮依次排列；对照使用独立按钮，以选中状态表示开启。移除眼睛按钮，保留 Alt / Option 查看原图操作。
- **紧凑的快捷键提示。** 关闭按钮左侧新增问号按钮，悬停显示快捷操作；缩小提示面板，并移除翻译耗时显示。
- **12 种界面语言同步更新。** 新增按钮提示、自动翻译状态和钉图操作说明均已接入多语言。

提供 Windows x64 安装程序及 Apple Silicon（M 系列、arm64）Mac DMG/ZIP。Mac 包继续使用 ad-hoc 签名、未经 Apple 公证，下载更新后需手动替换应用。Android 继续使用 1.4.7，保留原更新清单；本次没有 Intel Mac 安装包。

### Windows and Mac 1.4.10

- Double-click a pinned image to collapse it into a small desktop tile; double-click again to restore its previous size. Tiles remain draggable, and right-click closes the pin.
- Pinning while holding Alt (Option on Mac) preserves the original image.
- The toolbar now shows only the target language, followed by an automatic translation checkbox with a tooltip. When automatic translation is off, use the Translate button to translate manually.
- Translate, Reply and Compare now appear together in that order. Compare is an independent toggle with a selected state. The eye button is removed; Alt / Option still previews the original.
- A question-mark button beside Close opens a compact shortcut guide on hover. Translation timing is no longer displayed.
- New controls and hints are localized in all 12 interface languages.

Includes Windows x64 and Apple Silicon Mac installers. Mac builds remain ad-hoc signed and not Apple-notarized; downloaded updates require manual app replacement. Android remains at 1.4.7 with its existing update feed. Intel Mac builds are not included.
