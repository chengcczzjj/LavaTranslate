### Windows 和安卓 1.4.7

- **竖排译文按语言排版。** 中日韩译文保留直立竖排；英语、法语、德语、西班牙语、俄语、葡萄牙语、意大利语、越南语、泰语和阿拉伯语译文整行顺时针旋转 90°。原本横排的文字译后仍横排。
- **漫画气泡内自动安排列数。** 根据安全空白区域和译文长度调整字号与列数，均衡列长，避免文字重叠、裁切或越过气泡描边。同一气泡的多段译文共享字号并按阅读顺序显示。德语长单词优先完整保留，泰语按词边界换列，阿拉伯语保留行内方向。空间不足时显示省略号，复制仍可取得完整译文。
- **Windows 竖排识别修正。** 区分直立的中日韩字形与整行旋转的文字，修正多列阅读顺序。竖排、空白或低置信度识别结果会交给视觉翻译模型，避免把漏掉假名的日文误判成「已是中文」而跳过翻译。
- **桌面 CPU 识别优化。** 减少启动时的模拟识别，限制大图检测分辨率，同时保留原图裁字。Windows DirectML 路径保留原有分辨率和预热。

本次提供 Windows x64 安装程序和使用既有正式签名的 Android arm64 APK，以及两平台的应用内更新文件。安卓同步共享排版与视觉模型提示词改进，原生 OCR 引擎没有改动。

Mac 预览版源码包含 CPU 识别和竖排改进；本次没有 Mac 安装包，仍需在 Apple Silicon Mac 上构建并完成真机验收。已通过类型检查、378 项排版场景、31 项平台/OCR 回归和 6 项 Windows 兼容性检查；设置首页快捷键提示随自定义快捷键保存同步的行为也已验证。

### Windows and Android 1.4.7

- Vertical source text keeps upright Chinese, Japanese and Korean translations. The other ten supported target languages use whole lines rotated 90° clockwise; horizontal source text remains horizontal.
- Speech bubbles now use their verified blank area to choose font size and column count, balance column lengths, and avoid overlaps, clipping and bubble outlines. Paragraphs share one font size and retain reading order. German compounds stay whole where possible, Thai uses word boundaries, and Arabic retains its inline direction. Overflow is shortened visibly while copying retains the full translation.
- Windows OCR distinguishes upright vertical glyphs from rotated lines and restores column order. Unreliable or vertical OCR no longer skips image translation after being mistaken for the target language.
- Desktop CPU OCR avoids synthetic startup passes and limits large detection images while still recognizing from the original pixels. Windows DirectML keeps its existing resolution and warm-up.

Assets include the Windows x64 installer, Android arm64 APK signed with the existing release key, and both in-app update manifests. Android receives the shared layout and vision-prompt improvements; its native OCR engine is unchanged.

The Mac preview source includes the desktop fixes, but this release has no Mac installer. Build and verify it on an Apple Silicon Mac. Validation includes type checks, 378 layout cases, 31 platform/OCR tests, six Windows compatibility tests, and settings shortcut-hint synchronization.
