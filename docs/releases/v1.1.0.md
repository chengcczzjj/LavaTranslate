**First public release of LavaTranslate.** · LavaTranslate 首个公开版本。

### Download · 下载

**`LavaTranslate-Setup-1.1.0.exe`** — Windows 10/11 x64. Later versions update automatically. · 之后的版本会自动更新。

### Highlights

- **In-place translation**: the translation is drawn exactly where the original text was, with the same position, font size, color, weight and alignment.
- **Model-assisted OCR**: local PP-OCRv6 on the GPU. A vision model then fixes recognition errors, merges paragraphs, and leaves code and brand names untranslated.
- **Reply assistant**: write in your own language and it translates to the other person's language in the conversation's tone, with a back-translation. <kbd>Enter</kbd> copies it.
- **Bring your own key**: works with OpenAI, compatible relays, DeepSeek, Qwen, GLM, Moonshot, local servers, or Claude. Models are listed by estimated cost.
- **Automatic updates** from GitHub Releases.

### 亮点

- **原位翻译**：译文按原来的位置、字号、颜色、粗细、对齐方式直接盖在原文上；
- **模型辅助识别**：本地 GPU 跑 PP-OCRv6，再由能看图的模型纠正识别错误、合并段落，代码和品牌名不翻；
- **回复助手**：用自己的语言写，按对话语气译成对方的语言并附回译，<kbd>Enter</kbd> 复制；
- **用自己的 Key**：支持 OpenAI、兼容中转、DeepSeek / 通义 / 智谱 / Moonshot、本地模型和 Claude，模型按价格排序；
- **自动更新**（GitHub Releases）。
