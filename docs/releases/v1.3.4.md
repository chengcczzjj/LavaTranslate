### Changed

- **Reply translation waits a little longer.** When you type a reply (or use quick input), LavaTranslate now waits until you have paused for 1.8 s (quick input: 2.2 s) before translating, instead of 1.1 s / 1.4 s, so it no longer starts translating while you are still thinking about the next words. Press <kbd>Enter</kbd> to translate right away, as before. Applies to both desktop and Android.

### 改进

- **回复翻译多等一会儿再开始**。写回复（或快速输入）时，停顿 1.8 秒（快速输入 2.2 秒）后才开始翻译，原来是 1.1 秒 / 1.4 秒；中途停下来想下一个词时不会再急着翻译。想马上翻译照常按 <kbd>Enter</kbd>。桌面版和安卓版都已更新。
