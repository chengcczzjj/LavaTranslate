### Fixes

- **The hotkey could stop working entirely.** If the translation engine failed while the capture screen was opening (for example, "Claude account" was selected but Claude Code isn't installed), every later press of the hotkey did nothing. Engine errors now show on the toolbar, and the capture screen always opens.
- The "Claude account" engine is only used when Claude Code is actually installed. Otherwise the status page says so and the toolbar links straight to Settings.
- Settings migrated from the old name "Lens 截图翻译" no longer pick an engine that can't run here.
- The tray menu shows the shortcut aligned on the right and no longer has a wide empty column on the left.

### 修复

- **快捷键可能完全失效**：打开截图界面时如果翻译引擎出错（比如选的是「Claude 账号」但本机没装 Claude Code），之后再按快捷键都没有反应。现在引擎出错会显示在工具条上，截图界面总能正常打开；
- 「Claude 账号」引擎只在本机确实装了 Claude Code 时启用；没装时设置页如实提示，工具条上给出「去设置」按钮；
- 从旧名称「Lens 截图翻译」迁移来的配置，不会再选中本机用不了的引擎；
- 托盘菜单：快捷键靠右显示，左侧不再空出一大块。
