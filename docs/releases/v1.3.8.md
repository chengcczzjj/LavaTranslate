### Changed

- **Android: full-screen translation is back.** In 1.3.6 only the translated text blocks were drawn over the app, and on screens like Discord the layout fell apart. Translate now covers the whole screen with a frozen screenshot and the translation in place, exactly like the original screen. If any text on screen doesn't report its exact character positions, the whole screen is read with on-device OCR instead, so blocks no longer get squashed together.
- **Android: the translation doesn't get in your way.** You can scroll and tap the app through it: as soon as your finger touches the screen the translation steps aside, the first swipe scrolls the app, and a tap reaches the button underneath. When the app stops scrolling or changes page (about half a second later), the new screen is translated automatically. If you only tapped and nothing changed, the same translation comes back without a new screenshot.
- **Android: a smaller panel.** The panel that opens from the app icon is now a slim frosted-glass bar at the top of the screen (Translate / Reply / Settings, close on the right). It is about 40% lower than before, and you can drag it up or down. The capsule shown while translating is smaller too.
- **Android: the capsule** stays above the translation. Hold the eye to see the original, Reply opens the reply box, × returns to the panel. While the translation is out of the way, the first button turns into Translate.

### Fixed

- **Android:** after a cold start, the first translation could get stuck at "Translating 0/N".
- **Android:** the capsule could cover the reply box.
- **Android:** quick reply could show an old, enlarged screenshot in the background.
- **Android:** a screenshot taken during a page transition is discarded and retaken, so the translation no longer shows half of the old page.

### Note

- Desktop: no changes in this version (1.3.7 added 12 interface languages).

### 改进

- **安卓版：改回整屏翻译**。1.3.6 只把译文块画在应用上，在 Discord 这类界面排版会乱。现在点「翻译」会盖上整屏的冻结截图和译文，和原来的屏幕一模一样。只要屏幕上有一处文字读不到逐字位置，整屏就改用手机本地的文字识别（OCR），不再把文字挤成一团。
- **安卓版：译文不挡操作**。照常滑动、点按应用：手指一碰译文就让开，第一下滑动直接滚动应用，点译文就是点下面的按钮。应用滚动或换页停下约半秒后，自动翻译新的一屏；只是点了一下、屏幕没变，就把译文原样放回来，不重新截屏。
- **安卓版：面板更小**。点图标打开的面板改成屏幕顶部一条细长的毛玻璃横条（翻译 / 回复 / 设置，右边关闭），高度比之前低了约四成，可以上下拖动。翻译时贴边的小胶囊也缩小了。
- **安卓版：小胶囊**始终在译文上面：按住眼睛看原文，「回复」打开回复框，× 回到面板；译文让开时第一个按钮变成「翻译」。

### 修复

- **安卓版**：冷启动后第一次翻译可能卡在「翻译中 0/N」。
- **安卓版**：小胶囊可能挡住回复框。
- **安卓版**：快捷回复时，背景可能出现一张放大错位的旧截图。
- **安卓版**：截屏时碰上页面切换动画，会作废重截，不再出现半个旧页面。

### 说明

- 桌面版：本次没有变化（1.3.7 新增了 12 种界面语言）。
