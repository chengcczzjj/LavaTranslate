### Windows 1.4.8

- **降低输入法干扰风险。** 使用普通自定义快捷键时，后台不再安装全局低级键盘钩子；仅在截图交互或使用 Win + 空格时按需启用。Win + 空格不再通过模拟 Ctrl 屏蔽开始菜单，避免干扰以 Ctrl 切换状态的输入法。已有快捷键保持不变。
- **异常时自动释放空格。** 独立线程检查主进程和截图界面的存活期限，超时即放行按键并撤下不再需要的钩子。关闭截图、打开设置、界面崩溃或无响应、锁屏和休眠时释放拦截；丢失按键抬起事件后可恢复。Windows 不再使用依赖主线程释放的全局单空格快捷键。
- **减轻开机启动负担。** OCR 模型推迟到首次截图识别或打开设置查看状态时加载，不再随后台启动预热。
- **离线翻译意向调查。** 设置首页快捷键说明上方、通用设置快捷键上方新增小组件，说明可选离线模型约需下载 1.13 GB。点击「我想要」即可免登录匿名计票，服务端确认成功后在本机永久隐藏组件；断网或提交失败时保留重试。每个随机安装标识一票，重复提交不重复计数，超过 10 票（至少 11 票）后开始开发。当前版本不下载模型，也尚未提供离线翻译。

### Windows 1.4.8 — English

- Ordinary custom shortcuts no longer keep a low-level keyboard hook installed in the background. Hooks are enabled only for capture interaction or Win + Space. Start-menu suppression no longer injects Ctrl into input methods. Existing shortcuts are preserved.
- A native worker watchdog releases input when the main process or capture UI stops responding. Capture closure, settings, renderer failures, screen locking and suspension release capture ownership. Windows no longer registers a global bare-Space shortcut that depends on the main thread for cleanup.
- OCR loading and warm-up are deferred until recognition or a settings status request.
- A small offline-translation survey explains the optional approximately 1.13 GB model download. One click submits an anonymous vote without signing in. The card hides persistently only after acknowledgment; failed requests remain retryable. Random installation IDs deduplicate retries. Development starts after more than 10 votes (at least 11). Offline translation is not included in this release.

This release contains the Windows x64 installer and automatic-update files. Android remains on 1.4.7, with its existing update manifest retained; no new Android or Mac installer is included.
