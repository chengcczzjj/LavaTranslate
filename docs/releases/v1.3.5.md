### New

- **Android: turn it on once, use it anywhere.** The new default mode (Android 11+) runs entirely inside LavaTranslate's accessibility service. Enable it once under Accessibility and you are done: no overlay permission, no screen-sharing prompt each time, no persistent notification, and it is ready again after a reboot without opening the app.
- **Android: more ways to call it up.** Tap the system accessibility button (it fades when idle) or hold both volume keys, use LavaTranslate's own floating button (optional), or the new Quick Settings tiles "翻译屏幕" (translate screen) and "快捷回复" (quick reply). The tiles can be added from Settings with one tap.
- **Android: much lighter in the background.** Nothing runs while you are not translating. The translation interface and the text-recognition model load when you use them and are released 3 minutes after you close them, or as soon as the screen turns off, instead of staying in memory. In testing, the memory LavaTranslate kept after a translation went from about 700 MB, held until you exited, to about 45 MB once the screen had been turned off.

### Changed

- **Android: Settings** now starts with a choice of how to launch: **Accessibility (recommended)** or **Screen sharing**, the previous mode. Screen sharing still works and now ends the screen-sharing session 5 minutes after you close a translation, which removes the status-bar timer that kept redrawing every second.
- In accessibility mode, the floating button's menu offers "Hide floating button" instead of "Exit". There is nothing running to exit.
- Desktop: no changes in this version.

### 新功能

- **安卓版：开一次，随处可用**。新的默认方式（Android 11 起）整个运行在 LavaTranslate 的无障碍服务里：在系统「无障碍」里打开一次就好，不需要悬浮窗权限、不用每次授权截屏、没有常驻通知，开机后不用打开 App 就能用。
- **安卓版：更多唤出方式**。点系统的无障碍按钮（不用时自动变淡）或同时按住两个音量键、LavaTranslate 自己的悬浮球（可关），或新的下拉快捷开关「翻译屏幕」「快捷回复」（在设置里一键添加）。
- **安卓版：后台轻得多**。不翻译时什么都不运行：翻译界面和文字识别模型用时才载入，关掉 3 分钟后（或一关屏）就释放，不再一直占着内存。实测翻译过一次后，原来会一直占着约 700 MB 内存直到退出，现在关一次屏就降到约 45 MB。

### 改进

- **安卓版设置页**：最上面先选「启动方式」——**无障碍（推荐）**或原来的**截屏授权**。截屏授权方式照常可用，并且关掉翻译 5 分钟后会自动结束屏幕共享，状态栏那个每秒刷新的计时也随之消失。
- 无障碍方式下，悬浮球菜单里的「退出」换成了「隐藏悬浮球」：本来就没有在后台运行，不需要退出。
- 桌面版：本次没有变化。
