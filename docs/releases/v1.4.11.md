### Windows 与 Mac 1.4.11

- **修复 Windows 后台常驻后截屏 UI 不显示或层级被压住的问题。** 遮罩窗口在显示后主动重建顶置层级（`HWND_NOTOPMOST` → `HWND_TOPMOST`）并先恢复异常最小化状态，解决长期后台常驻后被全屏应用、Win+D、任务栏或 Win11 置顶降级压到下层的问题；主屏切前台失败时仍确保顶置，副屏也会在显示后提层。
- **避免截屏遮罩永久卡在全透明状态。** 为显示阶段的 `requestAnimationFrame` 增加渲染进程（120ms）与主进程（180ms）双层超时兜底，防止休眠唤醒、窗口遮挡或能效模式导致 `opacity` 停留在 `0` 而看不见界面；同步监听视口尺寸变化以适配显示器缩放或分辨率变更。
- **遮罩进程异常与休眠唤醒自愈。** 渲染进程退出或 Windows GPU 进程重启时自动销毁并重建预热的遮罩窗口；新建遮罩等待页面监听就绪后再发截图帧，避免首帧丢失；系统休眠恢复后重建遮罩并完整重装 `Win + 空格` 钩子；独立钩子线程意外退出时支持自动重启。
- **清理隐藏状态下的遗留状态。** 取消或超时关闭未显示的遮罩时也会重置渲染状态，避免后台心跳残留；保存截图弹窗结束后确保始终恢复顶置。

提供 Windows x64 安装程序及 Apple Silicon（M 系列、arm64）Mac DMG/ZIP。Mac 包继续使用 ad-hoc 签名、未经 Apple 公证，下载更新后需手动替换应用。Android 继续使用 1.4.7，保留原更新清单；本次没有 Intel Mac 安装包。

### Windows and Mac 1.4.11

- **Fix missing or buried capture overlay after staying idle in the background on Windows.** Overlay windows now restore minimized state if needed and re-assert topmost Z-order (`HWND_NOTOPMOST` → `HWND_TOPMOST`) after becoming visible on both primary and secondary displays, preventing demotion beneath fullscreen apps, Show Desktop (`Win+D`), the taskbar, or Windows 11 topmost demotion.
- **Prevent overlays from getting stuck invisible at `opacity = 0`.** Added dual fallback timers in the renderer (120ms) and main process (180ms) if `requestAnimationFrame` stalls after sleep, occlusion, or Windows Efficiency Mode, plus viewport resize synchronization for display metric changes.
- **Self-healing overlays and shortcut hook recovery.** Automatically recreates pre-warmed overlays after `render-process-gone`, Windows GPU restarts (`child-process-gone`), or system resume; waits for newly created overlays to finish mounting before sending capture frames; refreshes the `Win + Space` hook cleanly on unlock/resume and restarts the hook worker if it exits unexpectedly.
- **Cleaner cancellation and save-dialog cleanup.** Always resets overlay renderer state even if hidden before showing, and guarantees topmost restoration after the save-image dialog finishes.

Includes Windows x64 and Apple Silicon Mac installers. Mac builds remain ad-hoc signed and not Apple-notarized; downloaded updates require manual app replacement. Android remains at 1.4.7 with its existing update feed. Intel Mac builds are not included.
