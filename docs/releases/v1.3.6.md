### New

- **Android: the app icon opens a floating panel.** In accessibility mode, tapping the LavaTranslate icon shows a frosted-glass panel over whatever is on screen, with Translate, Reply and Settings, plus a close button. Drag it anywhere; it remembers its place. The system accessibility button opens and closes it, and the Quick Settings tiles still work.
- **Android: live translation.** Tap Translate and the panel shrinks into a small capsule at the screen edge while the translation appears in place over the original, without blocking the app underneath: you can still scroll and tap. The translation hides as soon as you scroll and comes back on its own about half a second after you stop. Text you have already seen is cached, so scrolling back shows it instantly and only new lines go to the model.
- **Android: the capsule.** Hold Compare to see the original text and let go to return to the translation. Reply opens the reply box. Exit returns to the panel.
- **Android: reads text directly.** On ordinary app screens LavaTranslate now reads the text and its exact position from the screen itself instead of running OCR on a screenshot, which is faster and more accurate. Games and text inside images still use on-device OCR.

### Fixed

- **Android:** in 1.3.5 the floating button could show up on the lock screen. Nothing is shown on the lock screen now; it all comes back after you unlock.
- **Android:** in 1.3.5 the app could stop responding to the icon or the accessibility button for a while after the screen was turned off and on. It now frees its memory when the screen turns off without restarting itself.

### Note

- To read on-screen text, the accessibility service now also asks Android for permission to read window content. It is only used after you tap Translate. If Android shows the accessibility prompt again after updating, allow it once.
- Desktop: no changes in this version.

### 新功能

- **安卓版：点图标就是悬浮面板**。无障碍方式下，点 LavaTranslate 图标会在当前屏幕上弹出一个毛玻璃悬浮面板：翻译 / 回复 / 设置，右上角关闭；可以拖到任意位置，会记住。系统无障碍按钮可以打开、收起面板，下拉快捷开关照常可用。
- **安卓版：实时翻译**。点「翻译」，面板缩成贴边的小胶囊，译文盖在原文位置上，而且不挡操作——照常滑动、点按。一滑动译文就藏起，停下约半秒后自动接着翻译；翻过的内容有缓存，滑回来立刻出现，只把新出现的文字发给模型。
- **安卓版：小胶囊**。按住「对比」看原文，松开回到译文；「回复」打开回复框；「退出」回到面板。
- **安卓版：直接读屏幕文字**。普通应用界面不再截图做 OCR，而是直接读取屏幕上的文字和精确位置，更快、更准；游戏、图片里的字仍在手机本地做文字识别。

### 修复

- **安卓版**：1.3.5 的悬浮球可能显示在锁屏上。现在锁屏时什么都不显示，解锁后自动回来。
- **安卓版**：1.3.5 在关屏再亮屏后，可能有一阵子点图标、无障碍按钮没反应。现在关屏时只释放内存，不再重启自己。

### 说明

- 为了直接读屏幕文字，无障碍服务多了一项「读取窗口内容」的能力，只在你点「翻译」后使用。更新后如果系统再次弹出无障碍提示，允许一次即可。
- 桌面版：本次没有变化。
