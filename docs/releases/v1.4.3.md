### Windows 1.4.3

- **Win + Space is the new capture shortcut.** Press once to select an area, or twice to translate typed text. Windows' reserved shortcut is handled directly, with held-key repeat suppressed.
- **Consistent shortcut guidance.** The home screen, settings, capture hints and tray tooltip display the configured shortcut. Recording a new shortcut and cancelling recording keep the shortcut state in sync.
- **Upgrade existing defaults.** The previous Windows default, Alt + Q, migrates to Win + Space. Other custom shortcuts are preserved.

While Win + Space is selected and LavaTranslate is running, this combination starts translation instead of switching input languages. Choose a different shortcut in Settings to restore the system action.

Includes the Windows x64 installer, differential-update blockmap and automatic-update manifest. Android remains at 1.4.1 with its existing update manifest retained. No macOS installer is included.

### Windows 1.4.3 更新

- **默认截屏快捷键改为 Win + 空格**：按一次开始框选，连续按两次进入输入文字翻译。专门处理 Windows 保留的组合键，长按不会重复触发。
- **快捷键提示保持一致**：首页、设置、截屏提示和托盘提示均显示当前配置；录制新快捷键或取消录制后，快捷键状态同步恢复。
- **升级时迁移旧默认键**：原默认 Alt + Q 自动改为 Win + 空格，其他自定义快捷键保留。

使用 Win + 空格且 LavaTranslate 运行时，该组合键用于翻译，不再切换输入语言。可在「设置 → 通用」中改用其他快捷键，恢复系统原有操作。

本次提供 Windows 64 位安装包、差量更新文件和自动更新索引。安卓仍为 1.4.1，保留原有更新索引；本次不提供 Mac 安装包。
