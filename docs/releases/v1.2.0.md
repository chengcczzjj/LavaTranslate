### New · 新功能

- **One place for every provider.** Settings → 翻译服务 now lists Gemini, OpenAI, DeepSeek, Qwen, Zhipu GLM, Kimi, Doubao, Claude, OpenRouter and Custom. Each provider has step-by-step instructions and a button that opens its API-key page. Every provider keeps its own key and model, so switching back and forth loses nothing.
- **Gemini support**, with its model list fetched from Google's native API.
- **2–4× faster on many models.** LavaTranslate now asks every model to skip "thinking", using each provider's own switch and falling back automatically. On DeepSeek V4 Flash a typical screenshot drops from ~5 s to ~2 s, and output tokens (cost) drop by about 65%.
- **Double-click the tray icon** to open Settings. A single click still starts a capture.
- Better translation of menu and tab names inside apps (e.g. "Pull requests · Issues").

### Changed

- **The "Claude account" login has been removed.** Anthropic doesn't allow third-party apps to use claude.ai logins or Pro/Max plan limits. Use a Claude API key instead.
- Your existing settings are migrated automatically. A relay or other OpenAI-compatible service becomes **Custom**.
