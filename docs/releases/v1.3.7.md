### New

- **Desktop: 12 interface languages.** Right-click the tray icon and pick **Language** to switch between System default, 简体中文, 繁體中文, English, 日本語, 한국어, Español, Français, Deutsch, Português, Русский, Italiano and Tiếng Việt. The change applies right away to the menu, the settings window, the translation toolbar, the reply box and notifications. The same choice is also under Settings → General. By default the interface follows your Windows display language.
- **Desktop: shorter, clearer text.** Settings descriptions, menu items and hints have been rewritten to say only what you need. The "Hotkey & startup" page is now **General**.
- **Desktop: language names in your language.** Source and target languages on the toolbar, the reply box and in Settings are now shown in the interface language (for example "Japanese" in English, "日语" in Chinese).
- **Desktop:** on first launch, the default target language is your Windows display language.

### Fixed

- **Desktop: ChatGPT sign-in.** When a ChatGPT sign-in expires or is revoked, LavaTranslate now says so ("sign in again") on the toolbar and in Settings, with a **Sign in again** button, instead of failing silently. Requests that start at the same time share one token refresh, and a temporary network problem no longer counts as an expired sign-in.
- **Desktop: settings file.** Settings are written to a temporary file first and then swapped in, so quitting mid-save (installing an update, shutting down) can't leave a half-written file. If the file is ever damaged, a copy is kept before defaults are restored.

### Note

- Android: no changes in this version.

### 新功能

- **桌面版：12 种界面语言**。右键托盘图标，在「语言」子菜单里选：跟随系统、简体中文、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Português、Русский、Italiano、Tiếng Việt。菜单、设置窗口、截图工具条、回复框和通知立即切换。设置 →「通用」里也能选。默认跟随 Windows 的显示语言。
- **桌面版：文字更精简**。设置页说明、菜单和提示都重写了一遍，只留必要的内容；「快捷键与启动」页改名为「通用」。
- **桌面版：语言名按界面语言显示**。工具条、回复框、设置里的原文 / 目标语言名称跟随界面语言（英文界面显示 Japanese，中文界面显示 日语）。
- **桌面版**：第一次运行时，默认目标语言取 Windows 的显示语言。

### 修复

- **桌面版：ChatGPT 登录**。登录过期或被撤销时，工具条和设置页会提示并给出「重新登录」按钮，不再无声失败；同时发起的请求只刷新一次令牌；网络临时出问题不再被当成登录过期。
- **桌面版：设置文件**。保存时先写临时文件再替换，安装更新、关机时中途结束也不会留下写了一半的文件；万一文件损坏，会先另存一份再恢复默认。

### 说明

- 安卓版：本次没有变化。
