### Windows 与 Mac 1.4.9

- **Mac 安装包和更新通道。** 提供 Apple Silicon（M 系列、arm64）的 DMG、ZIP 与 `latest-mac.yml`。Mac 与 Windows 共用当前桌面功能，包括 OCR、竖排排版和免登录离线翻译意向组件。
- **Mac 可以检查并自动下载更新。** 去掉针对所有 Mac 的更新禁用条件和固定的「预览版」状态。下载后点击「查看更新包」，在 Finder 中解压，退出软件，再将新应用拖入「应用程序」替换旧版。当前包使用 ad-hoc 签名、没有 Apple 公证，不提供自动替换安装，不更改 macOS 安全设置。
- **旧 Mac 预览版需手动升级一次。** 旧客户端的更新功能被写死为关闭，无法通过服务端发布文件自行恢复。请先下载本次 DMG 安装，以后即可使用新增的检查和自动下载功能。
- **更新状态更准确。** 找不到 Mac 清单时报告原因，不会误称已是最新版；关闭自动更新会取消尚未执行的启动检查。Windows 保留原有自动下载安装行为。
- **后续发版保留各平台更新通道。** 单独发布 Windows 时保留之前的 Mac 和 Android 更新清单，Mac 下载地址固定到对应安装包所在 Release。

验证包括类型检查、40 项平台/OCR/输入回归、7 项更新状态回归、2 项发布清单回归、5 项匿名计票测试和 378 项布局场景与 Windows/Mac 设置交互。Mac 使用 GitHub Apple Silicon 构建机运行原生依赖、CPU OCR、代码签名校验及更新包下载检查；完整屏幕权限、框选翻译和多屏交互仍需实际 Mac 用户环境验收。

Android 继续使用 1.4.7，保留原更新清单。本次没有 Intel Mac 安装包。

### Windows and Mac 1.4.9

- Adds Apple Silicon DMG/ZIP packages and the Mac update manifest, sharing current desktop OCR, layout and anonymous offline-interest features.
- Packaged Mac apps can check for updates and automatically download a verified ZIP. Choose **Show update package**, unzip it in Finder, quit LavaTranslate and replace the app in Applications. The current build is ad-hoc signed and not Apple-notarized; installation remains manual and macOS security checks remain in place.
- Older Mac previews require one manual upgrade because their updater was explicitly disabled.
- Missing Mac update feeds now report an error. Disabling automatic updates also cancels the pending startup check. Windows retains automatic installation.
- Windows-only releases retain existing Mac/Android feeds, with Mac asset URLs pinned to their original release.

Mac native dependencies, CPU OCR, signature and download checks run on a GitHub Apple Silicon runner. Screen permissions, end-to-end translation and multi-display interaction still require user-hardware validation. Android remains at 1.4.7; Intel Mac builds are not included.
