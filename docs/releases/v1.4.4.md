### Windows 1.4.4

- **Bundle the required VC++ runtime.** The Windows installer includes Microsoft's x64 runtime beside the application and OCR native module, addressing startup failures on PCs where the runtime is missing or outdated.
- **Explain startup failures.** Native-module loading and initialization errors now show a message with the error details and log location. Logging starts before native modules load and falls back to the temporary directory if the profile is not writable.
- **Validate the packaged runtime.** Packaging verifies the runtime files, and the package check confirms that OCR loads the bundled DLLs and can run both detection and recognition on the CPU.

Includes the Windows x64 installer, differential-update blockmap and automatic-update manifest. Android remains at 1.4.1; no macOS installer is included. The installer remains unsigned, so Windows may still show an unknown-publisher warning. Windows 10 installation still needs confirmation on an affected PC.

### Windows 1.4.4 更新

- **内置所需的 VC++ 运行库**：在主程序和 OCR 原生模块目录中随包提供微软 x64 运行库，修复缺少运行库或版本过旧时可能出现的启动失败。
- **明确提示启动失败原因**：原生模块加载或初始化失败时，显示错误详情和日志位置。日志在原生模块加载前启用；用户配置目录不可写时，回退到临时目录。
- **校验打包后的运行库**：打包时校验运行库文件；产物检查验证 OCR 实际加载随包 DLL，并完成检测、识别模型的 CPU 推理。

本次提供 Windows 64 位安装包、差量更新文件和自动更新索引。安卓仍为 1.4.1；本次不提供 Mac 安装包。安装包仍未签名，Windows 可能继续提示未知发布者。Windows 10 安装情况仍需在反馈问题的电脑上确认。
