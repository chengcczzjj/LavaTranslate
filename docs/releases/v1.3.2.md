### New

- **Android version.** Tap the floating button in any app to translate the whole screen in place, with the same layout engine as the desktop app. Tap the button or press Back to exit, long-press it for the menu. Includes the reply assistant, type-to-translate (long-press the button), two ways to capture the screen (screen-sharing permission, or a one-time Accessibility switch), on-device text recognition, and in-app updates. Download `LavaTranslate-Android-1.3.2.apk` below (Android 10+, arm64).
- **New icon:** a glowing drop of lava on black.

### Fixed

- After changing the target language, short pieces of text such as timestamps sometimes disappeared.
- Emoji are no longer drawn twice (once from the screenshot, once in the translation).
- Detecting which service an API key belongs to returns as soon as one service accepts it, instead of waiting for all of them.
- The "Test" button now translates "Good morning!" — models sometimes left "Hello, world" untranslated, which looked like a failure.

### 新功能

- **安卓版**：在任何应用里点一下悬浮球，整屏译文按原排版就地显示（与桌面版同一套排版）；单击悬浮球或按返回键退出，长按悬浮球打开菜单。带回复助手、输入文字翻译（长按悬浮球）、两种截屏方式（系统截屏授权，或在无障碍里打开一次免授权截屏）、手机本地文字识别、应用内更新。在下方下载 `LavaTranslate-Android-1.3.2.apk`（Android 10 及以上，arm64）。
- **新图标**：黑底上一滴发光的熔岩。

### 修复

- 换目标语言重新翻译后，时间戳这类短文字有时不显示。
- emoji 不再出现两次（原图里一次、译文里又一次）。
- 识别 API Key 属于哪家时，只要有一家通过就立即返回，不再等所有服务商都回应。
- 「测试」改用 "Good morning!"：模型有时把 "Hello, world" 原样保留，看起来像失败。
